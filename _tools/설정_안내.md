# 운영 설정 안내 (대표님이 직접 하실 일만)

모두 무료이며 새 서비스 가입은 없습니다. (GitHub · 구글 계정은 이미 쓰시는 것)

---

## 1. 관리자 열쇠(토큰) 만들기 — 컴퓨터마다 1회

`https://cnpsystem.kr/admin/` 에서 대문 사진과 포트폴리오를 직접 바꾸려면 열쇠가 필요합니다.
(2026-11-21 결정: 비공개 보관함 저장소는 쓰지 않습니다. 저장소 하나만 사용합니다.)

**열쇠가 저장되는 곳:** 열쇠를 입력한 그 컴퓨터의 그 브라우저 안에만 저장됩니다. 저장소나 서버에는 저장되지 않습니다.
그래서 맥북과 사무실 PC 각각 처음 한 번씩 입력해야 합니다. (컴퓨터마다 열쇠를 따로 만들면, 한 대를 잃어버려도 그 열쇠만 지우면 됩니다.)

1. GitHub 로그인 → 오른쪽 위 프로필 → **Settings** → 맨 아래 **Developer settings** → **Personal access tokens → Fine-grained tokens** → **Generate new token**
2. Token name: 예) `홈페이지 관리자 - 맥북` · Resource owner: `CNPSYSTEM` · Expiration: 원하는 기간(최대 1년 권장)
3. Repository access: **Only select repositories** → `CNP_HOMEPAGE` 선택
4. Permissions → Repository permissions → **Contents: Read and write** (나머지는 그대로)
5. Generate token → `github_pat_…` 값을 복사 → `https://cnpsystem.kr/admin/` 로그인 칸에 붙여 넣기

**새 컴퓨터에서 처음 접속할 때:** 위 1~5를 그 컴퓨터용으로 한 번 더 합니다.

**열쇠가 만료됐을 때:** 관리자 화면이 자동으로 로그인 화면으로 돌아가며 "열쇠가 만료되었거나 맞지 않습니다"라고 알려 줍니다.
GitHub → Fine-grained tokens → 해당 열쇠 → **Regenerate token** → 새 값을 복사해 다시 붙여 넣으면 끝입니다.

**공용 컴퓨터에서 썼다면:** 관리자 화면 오른쪽 위 `로그아웃`을 누르면 그 브라우저에서 열쇠가 지워집니다.

### 꼭 알아 둘 점
- 저장소가 **공개 저장소**라서, 관리자에 올린 사진은 '임시저장'이나 '비공개' 상태여도 저장소를 직접 찾아보면 보일 수 있습니다.
  사이트 주소(cnpsystem.kr)로는 열리지 않습니다. **공개해도 되는 사진만** 올려 주세요.
- 사이트에서 내리고 싶은 작품은 '삭제'하면 됩니다. (한 번 올렸던 사진은 저장소의 과거 기록에는 남습니다.)
- 관리자에서 저장하면 운영 사이트에 반영되기까지 1~2분 걸립니다.

## 2. 견적 메일 발송 — 연결 완료 (2026-11-19)

업무용 구글 계정의 Apps Script 웹 앱으로 `cnp3900@naver.com` 에 발송합니다. 답장 = 고객 이메일.
스크립트를 고칠 일이 생기면: https://script.google.com → 해당 프로젝트 → 수정 → **배포 → 배포 관리 → 수정(연필) → 새 버전 → 배포** (주소는 그대로 유지됩니다).

> 발송한 메일(첨부 포함)은 그 구글 계정의 "보낸편지함"에도 남습니다. 홈페이지 저장소에는 고객 정보·첨부가 저장되지 않습니다.
> 한도: 일반 구글 계정 하루 100통, 첨부 합계 15MB.
