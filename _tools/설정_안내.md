## 1. 비공개 보관함 저장소 만들기 (1회, 약 2분)

임시저장·비공개 작품 사진과 전체 내용은 **비공개 저장소**에만 저장됩니다. 공개 저장소에는 "공개 중"인 작품만 올라갑니다.

1. GitHub 로그인 → 오른쪽 위 `+` → **New repository**
2. Owner: `CNPSYSTEM` · Repository name: `CNP_HOMEPAGE_PRIVATE`
3. **Private** 선택 · **Add a README file** 체크 → Create repository

> 한 번 공개했던 사진은 비공개로 내려도 공개 저장소의 "과거 기록"에는 남습니다(사이트 주소로는 열리지 않음).
> 공개한 적 없는 임시저장 사진은 공개 저장소에 한 번도 올라가지 않습니다.

## 2. 관리자 열쇠(토큰) 만들기 — 컴퓨터마다 1회

**열쇠가 저장되는 곳:** 열쇠를 입력한 그 컴퓨터의 그 브라우저 안에만 저장됩니다. 저장소나 서버에는 저장되지 않습니다.
그래서 맥북과 사무실 PC 각각 처음 한 번씩 입력해야 합니다. (컴퓨터마다 열쇠를 따로 만들면, 한 대를 잃어버려도 그 열쇠만 지우면 됩니다.)

1. GitHub → 오른쪽 위 프로필 → **Settings** → 맨 아래 **Developer settings** → **Personal access tokens → Fine-grained tokens** → **Generate new token**
2. Token name: 예) `홈페이지 관리자 - 맥북` · Resource owner: `CNPSYSTEM` · Expiration: 원하는 기간(최대 1년 권장)
3. Repository access: **Only select repositories** → `CNP_HOMEPAGE` 와 `CNP_HOMEPAGE_PRIVATE` 두 개 선택
4. Permissions → Repository permissions → **Contents: Read and write** (나머지는 그대로)
5. Generate token → `github_pat_…` 값을 복사 → `https://cnpsystem.kr/admin/` 로그인 칸에 붙여 넣기

**새 컴퓨터에서 처음 접속할 때:** 위 1~5를 그 컴퓨터용으로 한 번 더 합니다.

**열쇠가 만료됐을 때:** 관리자 화면이 자동으로 로그인 화면으로 돌아가며 "열쇠가 만료되었거나 맞지 않습니다"라고 알려 줍니다.
GitHub → Fine-grained tokens → 해당 열쇠 → **Regenerate token** → 새 값을 복사해 다시 붙여 넣으면 끝입니다. (만료 전 GitHub 가 메일로 알려 줍니다.)

**공용 컴퓨터에서 썼다면:** 관리자 화면 오른쪽 위 `로그아웃`을 누르면 그 브라우저에서 열쇠가 지워집니다.

## 3. 견적 메일 발송 연결 (1회, 약 5분)

보내는 계정 = 대표님이 지정하는 **씨앤피 업무용 구글 계정** · 받는 곳 = `cnp3900@naver.com` (고정) · 답장 = 고객 이메일

1. 그 업무용 구글 계정으로 로그인한 상태에서 https://script.google.com → **새 프로젝트**
2. 기본으로 들어 있는 내용을 지우고 `_tools/apps_script_quote.gs` 내용을 전부 붙여 넣기 → 저장
3. 오른쪽 위 **배포 → 새 배포** → 유형 선택(톱니바퀴) **웹 앱**
   - 실행: **나** · 액세스 권한이 있는 사용자: **모든 사용자** → 배포
4. 권한 확인 창이 뜨면 그 업무용 계정으로 **허용**
5. 나온 **웹 앱 URL** (`https://script.google.com/macros/s/…/exec`) 을 클로드에게 알려 주기

이후 클로드가 주소를 연결하고, 가상의 고객 정보·샘플 파일로 시험 문의 1건을 보냅니다.
대표님은 네이버 메일함에서 ① 도착 ② 첨부 열림 ③ '답장' 눌렀을 때 시험 고객 주소가 뜨는지 확인해 주시면 됩니다.

> 참고: 발송한 메일(첨부 포함)은 그 구글 계정의 "보낸편지함"에도 남습니다. 홈페이지 저장소(GitHub)에는 고객 정보·첨부가 저장되지 않습니다.
> 한도: 일반 구글 계정 하루 100통, 첨부 합계 15MB.
